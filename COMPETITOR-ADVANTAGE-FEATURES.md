## 11. Design Direction (based on competitor analysis)

### 11.1 What Works (use this)

| Pattern | Source | Notes |
|---------|--------|-------|
| Dark background + vibrant accent | Fixkart (dark + gold) | Professional, premium feel |
| Card hover: slight lift (translateY -4px) | Fixkart | Small CSS touch, high impact |
| Sticky bottom bar on mobile (Call + WhatsApp) | Fixkart | Non-negotiable for local India |
| Animated brand logo marquee | All competitors | Shows brands covered, builds trust |
| Section: "How It Works" with 3 numbered steps + icons | Mheal, Phone Master | Reduces booking anxiety |
| Service area map / list with all locality names | Mobfixer, Gadzetspro | Directly answers "do you serve my area?" |
| Counter animation for customer count | Mheal | Feels alive, builds credibility |
| WhatsApp button with green (#25D366) always | All competitors | Never change this color |
| Accordion FAQ at bottom of every page | Fixkart, Mobfixer | Adds content, captures long-tail keywords |

### 11.2 What to Avoid (competitors do this wrong)

| Anti-Pattern | Source | Why Avoid |
|-------------|--------|-----------|
| Slow WordPress + Elementor | Phone Master | Slow load, poor CLS — use Next.js |
| Tiny text with low contrast | Gadzetspro | Hard to read on mobile |
| No lazy loading | Gadzetspro (old GA UA) | Kills page speed score |
| Pop-up before page loads | Gadzetspro (2-sec modal) | Annoying, hurts bounce rate — delay to 15 secs |
| Generic stock photos | Multiple | Use real shop / technician photos |
| Hiding price completely | Gadzetspro | Use "from ₹X" ranges — builds trust |
| No mobile sticky CTA | Phone Master | On mobile, no CTA visible on scroll |

### 11.3 Recommended Color Palette for AS & MS

| Role | Color | Hex | Rationale |
|------|-------|-----|-----------|
| Primary | Deep Electric Blue | `#1A6CF2` | Trust, tech, professional |
| Accent / CTA | Saffron Orange | `#F5820A` | Energy, action, Indian warmth |
| WhatsApp Button | WhatsApp Green | `#25D366` | Universally recognised |
| Background | Off-White | `#F8FAFC` | Clean, modern |
| Card Background | Pure White | `#FFFFFF` | Contrast against off-white |
| Text Primary | Dark Slate | `#0F172A` | High readability |
| Text Secondary | Cool Gray | `#64748B` | Subtext, labels |
| Border | Light Gray | `#E2E8F0` | Subtle structure |
| Success / Warranty | Emerald | `#10B981` | "Verified", "Warranty" badges |

## 13. Performance & Technical Checklist

| Feature | Source | Requirement |
|---------|--------|-------------|
| Lighthouse Performance ≥ 90 | Mobfixer (Next.js + ImageKit) | Use Next.js `<Image>` + WebP |

| Security headers | Fixkart | Add in next.config.js |
